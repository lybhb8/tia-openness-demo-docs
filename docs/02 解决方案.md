# 2 解决方案

## 2.1 概述

### 优点

本文介绍的解决方案可为您带来以下优势：

• 由于任务执行速度更快，效率得以提高

• 准确性，得益于一致流程的自动化

• 得益于程序支持的配置生成，调试时间短

• 通过有针对性地利用资源，提升竞争力

### 界定

本应用示例未对以下内容进行说明：

• 面向对象编程的基础知识

• 基于编程环境，例如 Microsoft Visual Studio

• TIA Portal 配置基础知识

必须具备这些主题的基础知识。
